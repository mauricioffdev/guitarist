# Mauricio Filho - Guitarist EPK

Static electronic press kit website for guitarist Mauricio Filho.

## Structure

- `index.html` - Page content and metadata
- `css/style.css` - Styles and responsive layout
- `js/main.js` - Interactions (menu, video loading, lightbox, email copy)
- `assets/img/` - Images and favicon
- `sitemap.xml`, `robots.txt` - SEO files

## Local preview

Open `index.html` in a browser, or run a local server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deployment

Deploy the repository contents as the site root (for example, GitHub Pages). Keep asset paths relative (`./css/`, `./js/`, `./assets/`).
